Research Projects

Latency-Aware Remote Driving Location Selection for Tele-Operation

Developed a framework for selecting optimal remote driving locations by accounting for network latency to ensure reliable and safe tele-operated vehicle control. The system evaluates real-time network quality metrics and adaptively assigns control to the lowest-latency operator location.

  • Modeled latency sensitivity for human-operated autonomous vehicles.
  • Designed algorithms to select geographically distributed driving centers based on real-time RTT measurements.
  • Validated reliability improvements under degraded network conditions.
  • Published in Applied Sciences (2021)
Tele-Operation Networking Autonomous Vehicles

Efficient Driver Assignment for Multi-Vehicle Remote Driving

Designed an efficient driver selection algorithm for scenarios where a single remote driver must control multiple vehicles simultaneously, optimizing task allocation based on priority, urgency, and system state.

  • Formulated the multi-vehicle control assignment as an optimization problem.
  • Proposed a real-time scheduling algorithm with low computational overhead.
  • Evaluated system responsiveness and safety under varying traffic conditions.
  • Presented at IEEE ICOIN 2021
Remote Driving Scheduling AI

RF Step Attenuator Design for Variable Gain Amplifier Systems

Designed an 8-stage RF step attenuator for use in variable gain amplifier circuits, targeting precision signal control for wireless communication systems.

  • Designed multi-stage attenuator topology for fine-grained RF signal control.
  • Optimized for linearity and minimal signal distortion across frequency bands.
  • Fabricated and characterized prototype circuits for validation.
  • Presented at IEEE CICN 2026.
RF Design Wireless Communications Hardware
